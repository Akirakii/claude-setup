# Moonsick

Online co-op game for 4–8 friends (Godot), repo `~/Playground/moonsick` (worktree `moonsick-hands`, branch `hands`).
All design docs live here since 2026-11-16; the repo keeps only `docs/build.md`, `docs/credits.md` and `docs/MOVED.md` (the old path of every doc).
The repo's `CLAUDE.md` still describes the old v0.1 (checked); `redo-race/redo-ideas.md` is the current design.
The worktree `moonsick-hands` still holds old copies of 27 docs on its branch; the ones here are current.
