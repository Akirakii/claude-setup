# Checks (in order; the first ✗ stops the idea; ✓ = pass, ~ = weak, ✗ = fail)

Target: an online co-op game for 3–6 friends on voice chat, made by one developer in about 3–4 months.
User's formula: "low content, low coupling but only high coupling on players".
Shapes: co-op, or semi-co-op (shared goal plus a private stake). Sources for the tests:
`~/Playground/game-design-research/research_notes/Idea search/loop1/research/`.

## 0. Force (why interact)
1. A pressure grows on its own. ✗ if nothing gets worse when nobody acts.
2. Only a specific friend's act relieves it, not the world or an item. ✗ if not. **No solo exit** (added cycle 7):
   name every other way out (a wall to push off, waiting for the right item, anyone being able to do it); ✗ if one
   works almost as well as the friend.
3. Relieving it costs or risks that friend. ~ if free.
4. The help spreads the harm onto the helper, not a back-and-forth of one resource. ~ if it only hands one
   resource around: that almost always fails "no fixed plan" later.
5. Something new is dealt each round (who, which harm). ~ if not.

## 1. Players act on each other (all must be yes; judge the idea line, and the choice must contain the friend)
1. My act lands on **one specific friend** (their body, view, options or next move), not on a pile
   everyone adds to, and not on a job I could do alone, just faster with help.
2. That friend **answers within seconds**, so both decide.
3. One named friend can be **helped or hurt** by it.
4. **Still two-way by round 5:** in the plan the crew settles into, nobody only waits, holds or obeys.

## 2. Formula
- **Low content:** humans, physics or one simple system make the opposition; 10 fresh rounds need ≤ 3
  arenas and one short list. ✗ if the objective is a place to reach, because that is levels.
- **Low feature coupling:** the rule fits in one sentence; ≤ 2 extra rules; nothing rewrites the core.
  Mark "needs a rule" while there is no rule yet.
- **Visible blame:** a failure is one visible person's action, seen in the moment.
- **3 and 6 players:** works at both, odd sizes too, nobody idle.
- **Hidden things:** if something is hidden, there's a way to uncover it and a reason to hide it.
- **Co-op gate:** time pressure makes people talk; new players at 3 can lose; one player can't carry it.
- **Lag (online):** the core act doesn't need two players to move within the same half second. ~ if it does
  (contact physics between two players, matching steps). Added cycle 2.

## 2b. Look (aesthetic; added cycle 2, the user's fantasy + logic + aesthetic)
1. **Shows the state:** the screen shows what the choice depends on (a stain, frost, fur, red eyes) on the body,
   without a number in the corner. ~ if a bar is needed.
2. **Fits the fantasy:** the look is the story's own world, not a generic one.
3. **One developer can make it:** one place, simple shapes, the effect drawn on the characters.

## 3. Objective
1. **No early finish:** nobody can be safely done and just wait.
2. **Last one standing:** a lone survivor can still finish or properly lose, without getting stuck.
3. **Not a place to reach** (see Low content). Leaving the arena is a place too (cycle 7, Harbor Jam).
4. **Both sides of the choice stay playable** (added cycle 11): the goal must not make one side always wrong (Ice
   Queen's "all twelve jewels" ruled out the crowbar, which shatters one).
Covered above: needs friends to the end (co-op gate), not a pile (1.1), blame (Formula).

## 4. No fixed plan
1. **Plan card:** could the crew write one plan before round 2 that still wins round 50? Yes = ✗.
2. Does something dealt or revealed during a round change *which* plan is best? Physics wobble alone is a no.
3. Does something answer the crew's habit? (A threat that targets what they keep doing, or a private reason to break the plan.)
4. By round 20, does each player still need to hear something they couldn't know before the round?
5. **No one-line trick:** ✗ if "hand it to whoever is farthest", "rotate", "make a decoy noise", or a fixed
   threshold ("pass it at half") beats it. A threshold is fine only if something dealt or a friend's last act
   moves it. Also ✗
   if a safe spot cancels the threat, or if the threat just hunts whoever holds / did / is most X.
6. **With a rule written** (added cycle 2): write the card the crew settles into. Nearly every rule has a 1–3 line
   card, so judge whether it lasts: ✓ if state the crew made (who carries what, who is slowed) breaks the card
   within a few rounds; ~ if it only bends it; ✗ if it holds. Overcooked's routine falls apart because its levels
   change; levels are content here, so harm spreading by help has to do that job.
7. **No dump, no super-player** (added cycle 8): name the most harm, parts or power one player can hold at once. ✗ if one
   player can soak up all the harm so the others stay clean, or collect everyone's power. Fix with a cap (one
   sickness at a time, two arm sockets).

## 5. Not an existing game
✓ nothing close · ~ a known game shares the core, but this one changes who decides what · ✗ same core.
