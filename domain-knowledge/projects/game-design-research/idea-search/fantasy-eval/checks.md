# Checks on fantasy only (2026-11-10 night)

User: "do the checks on the fantasy". The ideas are fantasies only (who you are, what you're doing), with
no rules. Only the checks that a fantasy can carry are scored; the rest need a rule (F2, F4, F6, G).
Full gates: `../loop1/checks.md`. Scores: ✓ 2, ~ 1, ✗ 0.

- **P from the fantasy:** does the fiction itself make players act on each other? (P1) one player's act lands
  on one named friend, not a pool or a shared job; (P2) the friend has something to answer back; (P3) a named
  friend can be helped or hurt by it. ✓ all three clearly; ~ one weak; ✗ any is no.
- **F1 content:** can this fantasy run on humans, physics or one simple system, with ≤ 3 arenas and one
  short list for 10 fresh rounds? ✗ if the fantasy needs many hand-made places, enemies or scripts.
- **F5 crew:** does the fiction fit 3 and 6 players (odd sizes too) with no one left out?
- **R from the fantasy:** does the fiction itself bring something that changes from round to round because
  of the players or of something dealt/revealed (not hand-made levels)? ✓ clearly; ~ only if a rule adds
  it; ✗ the fiction is one fixed situation.
- **N:** does a game with this fantasy *and* the same kind of player-on-player dependence already exist?
