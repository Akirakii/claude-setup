# The user's model of conscious and unconscious thinking (2026-11-19)

Built by the user over one chat, starting from "everything under a conscious methodical procedure is always superior".
Use their words: orchestrator, interface, raw power, shaped db, shapeless db, RAM.
Picture: `conscious-unconscious-model.png` (source `.svg`) in this folder.
The research behind the ✅/❌ lines is in `breaks-vs-more-work.md`.

## The two environments
| | Unconscious | Conscious |
|---|---|---|
| What it is | the raw power (user) | the orchestrator interface (user) |
| Role | produces the ideas and points at where to look | the steering (Claude; the user first said "never the drive"): holds the goal, works one idea out step by step, rejects what fails |
| How it runs | in the background, many things at once | one step at a time |
| Short-lived memory | temporary state that only shapes its next result and can't be read (Claude) | working memory, "RAM": a few items for seconds (Claude added it, the user adopted it) |
| Long-lived memory | the unconscious db, shapeless from the interface side (user); it holds patterns that behave like rules, not rules written out (Claude) | the shaped db: you can recall it and work on it (user) |

Psychology's names: explicit memory (shaped db), implicit memory (unconscious db), working memory (RAM). (from memory)

## The links
- Every conscious step is handed up by the unconscious: which thought comes next, "this follows", "this is off". (Claude, accepted)
- The interface sends a request built from the goal and the approach it is holding, and gets back results only.
- Practice moves a skill from conscious to unconscious.
- Feedback from the world tunes the unconscious db; a hunch is only good where there was a lot of practice with fast, clear feedback.
- A worded rule is a second copy in the shaped db that describes the pattern and can be wrong.
- The test "you can say how you got there, so it was conscious" is too weak (user caught it): the story can be written after the result.
  Better test: the steps were in mind before the result.

## What goes wrong
- **Fixation:** the orchestrator holds one approach, so every request brings back ideas near it.
- **Made-up story:** the interface can't read how a result was made, so it writes an explanation afterwards; the user compared it to AI hallucination.
- **Overthinking:** the orchestrator keeps running after it stopped improving the result; the cause is often an unconscious "this isn't settled" that keeps handing the thought back.
- **Choking:** the orchestrator steers a skill the unconscious runs better alone.

## Creativity
- In order: load the problem with hard work (conscious), the idea arrives (unconscious), work it out and check it (conscious).
- A conscious method can't do the exploring; it can change the request (drop an assumption, flip the problem, borrow from another field). (Claude, from memory)
- Two kinds of stuck: not enough work yet (keep working), and repeating (a short easy break, or a forced different start). ✅ researched
- The feeling of being stuck misleads both ways. ✅ researched
- The unconscious working a new problem alone in the background: ❌ least supported.

## Checked against research (2026-11-19; abstracts and search summaries, no full paper read)
Asked by the user: "could you validate its model against research and papers?"
| Part of the model | Supported? | Evidence |
|---|---|---|
| A conscious interface over many unconscious processors, with results posted to it | disputed | it is the shape of global workspace theory, a leading theory (Dehaene & Changeux 2011) [1]; a 2025 head-to-head test in Nature (256 people, 7 labs) challenged key predictions of it and of its rival [2] |
| Thinking splits cleanly into two kinds | disputed | Melnikoff & Bargh 2018: fast, automatic, unconscious and effortless don't reliably come together as one group; defenders answer that they never had to [3] |
| Working memory: a few items | ✅ | Cowan 2001: three to five chunks; the exact number is argued over [4] |
| Unconscious RAM (short-lived state outside awareness) | disputed | Soto 2011 found unseen items guiding a later task, barely above chance; Stein 2016 says the measure could be inflated [5]. Weakest box in the picture. |
| Two separate dbs (explicit and implicit) | disputed | the standard view, from amnesia patients who lose recall and keep priming; Berry, Shanks et al. 2014 fit the same patients better with one memory that varies in strength [6] |
| Only results cross: the interface can't read how a result was made | ✅ | Nisbett & Wilson 1977; choice blindness, Johansson 2005. One follow-up found people can reach more of it with special questioning [7] |
| Practice moves a skill down | ✅ | Fitts & Posner's three stages; Anderson 1982: practice builds procedures that no longer need the steps held in working memory [8]. Not the only route: patterns are also picked up with no conscious stage (from memory). |
| The unconscious db holds patterns that behave like rules | ✅ | what is stored is mostly small chunks plus some abstract structure (Knowlton & Squire 1996; Perruchet); "rules written out" is not supported, which matches the model's wording [9] |
| Feedback from the world tunes it | ✅ | Kahneman & Klein 2009: a regular environment, long practice, fast and clear feedback [10] |
| The interface steers and the raw power produces the ideas | ✅ | Beaty et al. 2016: one brain network generates candidates and the control network couples with it to keep them on the goal, during generating as well as checking [11] |
| Choking is the orchestrator steering a practiced skill | ✅ | Beilock & Carr 2001 for practiced skills; for thinking tasks it is worry filling working memory (Beilock 2004) [12] |

What it means for the picture (Claude): the links hold up better than the boxes.
The three disputed boxes are the clean two-way split, the two separate dbs and the unconscious RAM; the evidence allows one memory read in two ways, and a gradual scale where the picture has two bands.

## To investigate later (user, 2026-11-19: "record this for future investigation")
The user's question: "there is a possibility that there are no separated systems but grays in between? one axis".
- Claude's answer, not researched beyond the sources above: grays yes, but several axes, not one.
  A process has separate properties that don't move together: how fast it is, whether you're aware of it, whether you started it on purpose, how much effort it costs.
  A practiced skill is fast and effortless but started on purpose and watchable; a worry that keeps coming back is slow and in awareness but not chosen.
- For memory the one-db view does have one axis: how strong the memory is, with recall needing more strength than a skill.
- The two bands of the picture would then be the two far corners, still useful because fixation, made-up stories and practice sit near one corner or the other.
- Open: which axes the research agrees on, whether the picture should be redrawn on axes, and whether the two dbs should become one db read in two ways.
- Start from sources 3 and 6 above (Melnikoff & Bargh 2018; Berry, Shanks et al. 2014).
