# Brief for the comparing critic: is this idea fun with friends?

You judge one co-op game design for friend groups (3–6 friends on voice, playing for laughs and shouting) by comparing it to ten shipped designs whose audience is known.
Judge only what is written. Don't guess which real games the sheets are, and don't use anything you know about any real game.

Read ONLY:
1. `ladder.md` in this folder;
2. the ten reference sheets `sheets/g01.md` … `g10.md` in this folder (skip each last "Sources:" line, never open links);
3. the design file(s) named in your task.
Open no other file. No web except the novelty searches in step 0. At most 20 tool calls.

Rules of judging:
- "(not found)" in a sheet means the writer couldn't find the fact: unknown, never a fault and never a merit.
- A long or detailed sheet is not a better design. A trait counts only when a written rule causes it; a feeling line or a scene alone doesn't.
- Judge the design alone: no team size, months, bots or voice app.

For each design named in your task, write:
0. **Novelty, kept apart from the verdict:** name the design's core act in one line. Is it the core act of any sheet on the ladder? If the task says the design is a new idea, also run at most 3 web searches for a shipped or announced co-op game with the same core act (the only web use allowed), and name what you find.
   Mark it "new", "near <game or sheet>: different because …", or "follows <game or sheet>".
   Novelty does not change the verdict on fun: a copy of a fun game is still fun. It is reported so the reader knows; on the ladder the games that followed an earlier one found few players.
1. **The seven traits**, each yes / partly / no, with the written rule that causes it (or "no rule"):
   1. A player's action changes what a teammate must do in that same second, for most of the listed choices.
   2. A failure turns into a story that keeps the failed player involved (carried, filmed, revived, dragged along), not a silent wait.
   3. Voice itself is under a rule (fades by distance, heard by creatures, recorded, cut off).
   4. A repeated "one more, or leave now" call where the whole crew shares the loss.
   5. One player holds information the others need and can't see themselves.
   6. Every round differs without the crew seeking new content.
   7. The target rises, so every run ends in a failure the crew caused.
2. **The two reference sheets it is closest to**, and what it has that they lack and lacks that they have.
3. **Is it fun with friends?** yes, maybe or no, with the reason in two lines.
   The question is whether a group of friends would laugh, shout and want another round, not how many copies it would sell: popularity moves with time and trends and is not what you are judging.
   Use the ladder as examples of fun: the tier A and B sheets are designs many friend groups kept playing, the tier D sheets are designs almost nobody did.
   "yes" = it has what the tier A and B sheets have; "maybe" = it sits with tier C; "no" = it sits with tier D.
   Also name the two sheets it sits between.
4. **Holes of this design alone:** at most five, each with the best move that breaks it, and whether a tier A sheet has the same hole (name it). A hole a tier A sheet shares is listed and is not held against the design.
5. **What you could not break.**
6. **The smallest change that would make it more fun with friends** (your opinion).

End each design's part with:
```
PLACE BLOCK <design id>
fun_with_friends: yes|maybe|no
novelty: new|near|follows
between: g?? g??
traits: <seven marks, Y P or N, in order>
END
```
Then reply in terse caveman style, under 100 words: per design the tier, the seven marks, and the worst hole.
