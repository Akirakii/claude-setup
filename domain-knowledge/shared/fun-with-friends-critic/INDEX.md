# The comparing critic: is a co-op idea fun with friends?

| File | What it holds | Read when |
|---|---|---|
| `brief.md` | the judge's brief: the seven traits, the verdict (yes / maybe / no), novelty on its own line | running the comparing critic |
| `ladder.md` | ten shipped co-op games in four tiers by Steam review count, with release dates and whether each core act was new | the judge reads it; also when asking why an idea was placed where it was |
| `sheets/` | rule sheets of 14 shipped games under made-up names, and `TEMPLATE.md` for writing a new idea the same way | writing an idea sheet; the judge reads g01–g10 |
| `key.md` | which sheet is which real game, with review counts; the judge must never read it | checking a placement against the real game |

How it was checked and how far to trust it: the top-level note `critic-baseline.md`.
