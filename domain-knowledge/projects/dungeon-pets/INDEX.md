# Dungeon Pets

First-person creature-pack roguelike; repo `~/Playground/dungeon-pets` (failed, archived 2026-10-31).
The design docs live here since 2026-11-16; the repo keeps `docs/MOVED.md` and the art prompt files next to the art.
The worktree `dungeon-pets-base` is the first commit and still holds its own old copies.

| Doc or folder | What it holds | Read when |
|---|---|---|
| `DESIGN.md` | the design brief: rules and balance | looking back at the design |
| `research.md` | reference games and what was taken from each (127 KB) | pet, roguelike or pack-combat questions |
| `postmortem/` | why it failed | comparing why projects failed |
| `pivot-constraints/` | the constraints for the new direction, which became Assemblia | the pivot |
| `meshy-art/` | the Meshy art workflow, the shared style and every character | making character art with Meshy |
